# Stats Mastery

> **The complete interactive visual curriculum for statistical mastery.**
>
> 36 comprehensive, self-contained interactive modules covering probability, classical inference, regression, causal inference, Bayesian modeling, and specialist depth — with interactive simulations, formula proofs, and self-assessment exams.

---

## 🚀 Quick Start

**No build tools, bundlers, or server runtimes required.**

Simply open `index.html` in any modern web browser:

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Or serve locally with any static web server:

```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.

## 📥 Ingesting New Checkpoints

When a new snapshot ZIP arrives (e.g. `stats-mastery (20).zip`):
1. Drop the ZIP file into this project directory.
2. Run the automated ingestion tool:
   ```bash
   python ingest_checkpoint.py
   ```
The tool will automatically:
- Detect and extract all new module files.
- Re-order and align [`index.html`](index.html) in strict sequential order (Stage 1 to 7 / Items 1 to 36).
- Instate runtime sorting guards so future snapshots never cause visual reordering.
- Update curriculum chapter/lab/question counts in [`README.md`](README.md).
- Safely archive the ZIP file into `.snapshots/`.
- Create a clean Git commit with the checkpoint's date and name.

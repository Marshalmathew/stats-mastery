Part I · One variable

1What a random variable really is Beginner

Despite the name, a random variable is neither random nor a variable. It is a function: a rule that takes the outcome of a random experiment and returns a number.

DefinitionAn experiment has a sample space Ω (all possible outcomes) and probabilities on it. A random variable is a function X : Ω → ℝ. The randomness lives in which outcome occurs; X just reads off a number from it.

Roll two dice: the outcome is a pair like (3, 5). The sum, the maximum, the product and “was it a double?” are four different random variables defined on the same experiment. Same randomness, different numbers read off. In a bank: the experiment is “pick a customer”; PD flag, balance, number of transactions and days past due are all random variables on that one experiment.

Lab 1 · One experiment, many random variables

The grid is the sample space (36 equally likely outcomes). Choose the rule X; each cell shows the number X assigns. The bars are the distribution of X, computed exactly. “Roll” adds real simulated rolls on top.

Discrete vs continuous. If X takes countable values (dice, counts of defaults) it is discrete and described by probabilities of exact values. If X can take any value in an interval (a balance, a time) it is continuous, and any single exact value has probability 0 — only intervals get probability. Many real variables are mixed (a balance that is exactly 0 for many customers, continuous otherwise).

Notation trapCapital X is the random variable (the rule). Lower-case x is a particular number it might produce. P(X = x) reads “the probability that the rule returns x”. Mixing them up is the root of a lot of confusion later.

2PMF, PDF and CDF Beginner

The distribution of X says how probability is spread over its possible values. Three equivalent descriptions:

  • PMF (discrete): p(x) = P(X = x). Probabilities, so 0 ≤ p ≤ 1 and Σ p(x) = 1.
  • PDF (continuous): f(x) with P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx. A density, not a probability: it can exceed 1 (a narrow spike), and it integrates to 1.
  • CDF (both): F(x) = P(X ≤ x). Always rising from 0 to 1. It is the universal description: P(a < X ≤ b) = F(b) − F(a), and its inverse is the quantile function (percentiles, VaR).

Lab 2 · Distribution explorer

Pick a distribution and its parameters, then choose an interval [lo, hi]. The shaded area (or highlighted bars) is the probability. The lower chart is the CDF: read the same probability as the vertical gap between two points.

The distributions to know cold: Bernoulli/Binomial (counts of successes: defaults, fraud flags), Poisson (event counts in a period), Exponential (waiting times), Uniform, Normal (sums and averages), Lognormal (positive, right-skewed: balances, claim sizes, transaction amounts). Try each one and notice how mean and variance depend on the parameters.

3Expectation and the law of large numbers Beginner

The expectation (mean) of X is its probability-weighted average: the long-run average you would see over infinitely many repetitions, and the balance point of the distribution.

discrete: E[X] = Σ x · p(x)
continuous: E[X] = ∫ x · f(x) dx

Four rules that do most of the work

  1. Linearity: E[aX + b] = a·E[X] + b and E[X + Y] = E[X] + E[Y] — always, even if X and Y are dependent. This is the most useful fact in probability; it turns hard counting problems into easy sums of indicators.
  2. Indicators: for an event A, E[1_A] = P(A). Expected number of defaults in a portfolio = Σ PDᵢ, no matter how correlated they are.
  3. LOTUS (law of the unconscious statistician): E[g(X)] = Σ g(x) p(x) — you don’t need the distribution of g(X), just that of X.
  4. Jensen: E[g(X)] ≠ g(E[X]) in general. For convex g, E[g(X)] ≥ g(E[X]). So E[X²] ≥ (E[X])², E[1/X] ≥ 1/E[X], and the average of a lognormal is above exp of the average of its log.

The law of large numbers says sample averages converge to E[X] as n grows. The next lab lets you watch it — and watch it fail when the mean does not exist.

Lab 3 · Five running averages racing toward the mean

Each coloured line is an independent sequence of draws; the y-value is the average of the first n. The x-axis is log₁₀ n. The dashed line is the true mean. Try Cauchy last.

Convergence has a speed, and sometimes no destinationFor finite variance σ², the sample mean wobbles around E[X] with size σ/√n — to halve the error you need 4× the data. For the lognormal, rare giant values keep yanking the average (slow convergence). For the Cauchy, the average of n draws has exactly the same distribution as a single draw: averaging buys you nothing, because the mean doesn’t exist.

4Variance, standard deviation and transformations Beginner

The mean tells you where the distribution sits; the variance tells you how widely it is spread: the average squared distance from the mean.

Var(X) = E[(X − μ)²] = E[X²] − (E[X])² SD(X) = √Var(X)

Squaring makes distances positive and punishes big deviations; SD brings the unit back to X’s own units. The shortcut formula E[X²] − μ² is also the Jensen gap: variance is how much E[X²] exceeds (E[X])².

Var(aX + b) = a² · Var(X) (shifting does nothing; scaling squares)
Var(X + Y) = Var X + Var Y + 2 Cov(X,Y) (Chapter 7)
Independent X, Y: Var(X + Y) = Var(X − Y) = Var X + Var Y — both add

Part II · Several variables

5Joint, marginal and conditional distributions Intermediate

Real problems involve several variables at once. The joint distribution of (X, Y) assigns probability to pairs. From it you can get:

  • Marginals: sum/integrate out the other variable: pX(x) = Σy p(x, y). Forget Y and look only at X.
  • Conditionals: slice and renormalise: p(y | x) = p(x, y) / pX(x). “What does Y look like given X = x?”
  • Independence: p(x, y) = pX(x) · pY(y) for all x, y — knowing X tells you nothing about Y. Equivalent: every conditional equals the marginal.

For a bivariate normal with standard marginals and correlation ρ, the conditional law has a clean closed form:

Y | X = x ~ Normal( ρ·x , 1 − ρ² ) — mean moves with x; spread shrinks by the factor (1 − ρ²)

Lab 5 · Slice the cloud

1,500 points from a bivariate normal. Yellow points are those with X inside the narrow band around your chosen x. Their average height and spread are the conditional mean and SD of Y.

Notice: conditioning reduces uncertainty (conditional SD < marginal SD of 1) exactly when ρ ≠ 0. That reduction is what a predictive model exploits. Regression, in one sentence, is “estimate E[Y | X]”.

6Covariance and correlation Intermediate

Covariance measures whether two variables move together: the average product of their deviations from their means.

Cov(X, Y) = E[(X − μₓ)(Y − μ_y)] = E[XY] − E[X]·E[Y]
Corr(X, Y) = ρ = Cov(X, Y) / (SD(X) · SD(Y)) always −1 ≤ ρ ≤ 1

Covariance has units (dollars × days…) and no natural scale; correlation divides the units away. Correlation measures only linear association — and is wrecked by outliers. Two variables can be perfectly dependent and have correlation zero.

Lab 6 · Five scatterplots, one correlation number

Each pattern has a very different story. Compare Pearson r (linear), Spearman (monotone, rank-based), and covariance.

Independent ⇒ uncorrelated, but NOT the reverseIf X and Y are independent, Cov = 0. The parabola and the circle show the converse is false: strong, perfectly structured dependence with r ≈ 0. And in the “three groups” pattern, the pooled correlation is strongly positive although within every group it is negative: Simpson’s paradox — the cause of many wrong conclusions from aggregated data.

7Variance of sums, and why diversification works Intermediate

The single most reused formula in quantitative finance and risk:

Var(aX + bY) = a²·Var(X) + b²·Var(Y) + 2ab·Cov(X, Y)
general: Var(Σ wᵢXᵢ) = Σᵢ Σⱼ wᵢ wⱼ Cov(Xᵢ, Xⱼ) = wᵀ Σ w

With ρ = 1 the SDs just add; with ρ < 1 they add less than that. Combining imperfectly correlated pieces shrinks risk, and the lower the correlation, the larger the saving. Conversely, positive correlation among many small risks leaves a stubborn floor of risk that no amount of adding more of them can remove — the core of Chapter 14.

Lab 7 · Two-asset portfolio

Notice two things: expectation is linear (portfolio return is just the weighted average, correlation irrelevant), but variance is not — it depends on the covariance. And with low ρ the minimum-variance portfolio can have lower SD than either asset alone.

8Conditional expectation and the law of total variance Advanced

E[Y | X] is itself a random variable (a function of X). Two laws govern it:

Law of total expectation: E[Y] = E[ E[Y | X] ]
Law of total variance: Var(Y) = E[ Var(Y | X) ] + Var( E[Y | X] )
= within-group variance + between-group variance

Averaging group means gives the overall mean (weighted by group sizes). Overall variance is the average within-group variance plus the variance of the group means: a heterogeneous population is more spread out than any of its parts. This identity is ANOVA, the R² of a regression (explained = between, unexplained = within), and the reason mixing customer segments inflates variance.

Lab 8 · A two-segment customer population

Segment 1 has share π, mean m₁, SD s₁; segment 2 has the rest. Watch within + between add up to the total variance, and see how R² (the share explained by knowing the segment) behaves.

Why this matters for modellingR² = Var(E[Y | X]) / Var(Y): the fraction of variance a model with features X could ever explain. If within-group variance dominates, no feature set based on the grouping can predict individuals well, however many customers you have.
Part III · Shape, estimation and tails

9Moments, skewness, kurtosis and heavy tails Advanced

The k-th moment is E[Xᵏ]; central moments are taken around the mean. Mean = 1st moment, variance = 2nd central moment. The next two describe shape:

skewness = E[(X−μ)³] / σ³ (asymmetry; > 0 means a long right tail)
excess kurtosis = E[(X−μ)⁴] / σ⁴ − 3 (tail weight relative to the normal; 0 for a normal)

Higher moments are dominated by extreme values. For heavy-tailed distributions some moments are infinite: Student-t with 3 degrees of freedom has finite variance but infinite kurtosis; Cauchy has no mean at all. Then the sample versions are unstable — and the textbook formulas built on them mislead.

Lab 9 · Shape and tail stability

8,000 draws from the chosen distribution. See skewness, excess kurtosis, how many values land beyond 3 SD (a normal gives 0.27%), and how unstable the sample variance is across 300 repeats at n = 100. Press Resample several times with Student t(3) and watch the numbers jump.

Financial and behavioural data are rarely normalTransaction amounts, claim sizes, balances and returns are skewed and fat-tailed. Using “mean ± 3 SD” as an outlier rule or as a tail-risk estimate understates extremes badly. Use quantiles and robust statistics, and model the tail explicitly (extreme value theory, Chapter “next steps”).

10Estimating these quantities from data: bias and n − 1 Advanced

Everything above describes the population. From a sample you compute estimates, which are themselves random variables, with their own mean and variance (the sampling distribution). The estimator’s expectation tells you about bias; its variance tells you about precision.

sample mean: x̄ = (1/n) Σ xᵢ E[x̄] = μ (unbiased), Var(x̄) = σ²/n
sample variance: s² = (1/(n−1)) Σ (xᵢ − x̄)² E[s²] = σ² (unbiased)
divisor n instead: E = ((n−1)/n)·σ² (biased low)

Why n − 1? Deviations are measured from x̄, which was fitted to the same data and sits closer to the points than the true μ does, so the raw sum of squares is too small. Using n − 1 degrees of freedom exactly repairs it. Note that s itself (the standard deviation) is still biased low, by Jensen (√ is concave).

Lab 10 · The bias you can see

20,000 samples of size n from Normal(0, σ=2) (true variance 4). Average the estimates.

Also remember the standard error of the mean, σ/√n, is the “SD of an average” — the quantity behind every confidence interval and z-score in the p-value course. And estimating covariance matrices from few samples is much noisier than estimating means, a central problem in high-dimensional risk modelling.

Part IV · Geometry, bounds and risk

11Covariance matrices and the geometry of variance Expert

With p variables, all variances and covariances sit in a symmetric covariance matrix Σ (diagonal = variances, off-diagonal = covariances). Two facts make it powerful:

Var(aᵀX) = aᵀ Σ a ≥ 0 (so Σ is positive semi-definite)
Σ = V Λ Vᵀ eigenvectors V = principal axes, eigenvalues Λ = variance along each axis

Data with covariance Σ forms an ellipse (ellipsoid): axes point along the eigenvectors, with lengths ∝ √eigenvalue. PCA is just this eigen-decomposition. The Mahalanobis distance d² = (x − μ)ᵀ Σ⁻¹ (x − μ) measures how far a point is in units of that shape, accounting for scale and correlation; for a normal, d² follows a χ² law with p degrees of freedom (for p = 2: P(d² ≥ t) = e−t/2).

Lab 11 · The covariance ellipse

Set σₓ, σ_y, ρ. The ellipses are 1, 2 and 3 Mahalanobis-SD contours. Place a test point: its Euclidean distance (ordinary ruler) can mislead; the Mahalanobis distance respects the data’s shape.

Try ρ = 0.8 and put the test point at (2.5, −1.5): it is only ~2.9 units from the origin by the ruler, but it lies against the correlation, so it is a genuine multivariate outlier (large Mahalanobis distance, tiny probability) even though each coordinate is unremarkable on its own. This is the basis of multivariate anomaly and fraud screening.

12Inequalities: what you can say without knowing the distribution Expert

  • Markov (X ≥ 0): P(X ≥ t) ≤ E[X] / t. Needs only the mean.
  • Chebyshev: P(|X − μ| ≥ kσ) ≤ 1/k². Needs only mean and variance. Guarantees ≥ 75% within 2 SD and ≥ 89% within 3 SD for any distribution.
  • Jensen: E[g(X)] ≥ g(E[X]) for convex g.
  • Cauchy–Schwarz: |Cov(X, Y)|² ≤ Var(X)·Var(Y), which is exactly why |ρ| ≤ 1.

These bounds are valid for every distribution — so they are loose for any specific one. The table shows how loose.

13Sums, averages and the central limit theorem Expert

If X₁…Xₙ are independent with mean μ and SD σ, the average satisfies E[X̄] = μ and SD(X̄) = σ/√n, and the CLT says the standardised average becomes normal:

Z = (X̄ − μ) / (σ / √n) → Normal(0, 1) as n → ∞, with error roughly proportional to skewness/√n

This is why normal-based inference works for means of almost anything. But it is an asymptotic statement: for skewed or heavy-tailed data and moderate n, the tails — exactly what p-values and risk limits depend on — are still visibly off.

The delta method: variance of a function

If an estimate θ̂ has variance v, then for smooth g: Var(g(θ̂)) ≈ g′(θ)² · v. Example: the log of a ratio, the SE of an odds ratio, or the variance of a log-transformed average all come from this one-line approximation (a first-order Taylor expansion plus the variance-scaling rule from Chapter 4).

14Risk application: expected loss, correlated defaults and tail capital Expert

Bring it all together. A portfolio of n loans, each defaulting with probability PD; the number of defaults D = Σ Iᵢ (indicators). Linearity gives the mean regardless of correlation; variance does not:

E[D] = n · PD (no assumption on dependence)
Var(D) = n·PD(1−PD) · [ 1 + (n−1)·ρ ] (ρ = pairwise correlation of default indicators)
SD of the default rate D/n → √( PD(1−PD) · ρ ) as n → ∞ — a floor that diversification cannot remove

With ρ = 0, the default rate’s SD shrinks like 1/√n and large portfolios become almost deterministic. With even a tiny ρ (say 0.02), the 1/√n term disappears and a systematic component remains.
